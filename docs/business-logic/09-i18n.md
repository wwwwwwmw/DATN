# 09. DA NGON NGU (i18n - Internationalization)

## Tong quan
San pham ho tro 2 ngon ngu:
- **Tieng Viet** (vi-VN) - Ngon ngu mac dinh
- **Tieng Anh** (en-US) - Ngon ngu phu

Nguoi dung co the chuyen doi ngon ngu bat ky luc nao qua Cai dat.

---

## Chuc nang

### 9.1. Chuyen doi ngon ngu
- **Actor**: Tat ca nguoi dung
- **Vi tri**: Settings / Cai dat > Ngon ngu
- **Luong**:
  1. Nguoi dung vao Cai dat > Ngon ngu
  2. Chon "Tieng Viet" hoac "English"
  3. He thong cap nhat:
     - Luu preference vao user profile (DB)
     - Luu vao localStorage (browser)
     - Reload giao dien voi ngon ngu moi
  4. Lan dang nhap tiep theo: tu dong dung ngon ngu da chon

### 9.2. Pham vi da ngon ngu

| Thanh phan | Da ngon ngu? | Ghi chu |
|------------|-------------|---------|
| UI labels (buttons, menus, headings) | Co | JSON translation files |
| Thong bao (notifications) | Co | Template co i18n |
| Error messages | Co | Backend tra ma loi, frontend dich |
| Chat AI responses | Co | LLM tra loi theo ngon ngu user |
| Ma ICD-10 (name) | Co | DB co name_vi va name_en |
| Du lieu nhap boi user (chan doan, ghi chu) | KHONG | Giu nguyen ngon ngu user nhap |
| Ten bac si, benh nhan | KHONG | Ten rieng khong dich |
| Dia chi phong kham | KHONG | Dia chi thuc te khong dich |
| API response keys (field names) | KHONG | Luon tieng Anh (chuan REST) |

## Kien truc i18n

### Frontend (React)
```
Dung thu vien: react-i18next

frontend-web/
  src/
    i18n/
      index.js           # i18n config
      locales/
        vi/
          common.json     # Labels chung: "Dang nhap", "Dang ky", ...
          dashboard.json  # "Bang dieu khien", "Lich kham", ...
          appointments.json
          xray.json
          chat.json
          medical.json
          settings.json
          notifications.json
        en/
          common.json     # "Login", "Register", ...
          dashboard.json  # "Dashboard", "Schedule", ...
          appointments.json
          xray.json
          chat.json
          medical.json
          settings.json
          notifications.json

Su dung trong component:
  import { useTranslation } from 'react-i18next';

  function Dashboard() {
    const { t } = useTranslation('dashboard');
    return <h1>{t('title')}</h1>;  // "Bang dieu khien" hoac "Dashboard"
  }
```

### Backend (Django)
```
Dung he thong i18n co san cua Django:

- settings.py:
    LANGUAGE_CODE = 'vi'
    LANGUAGES = [('vi', 'Tieng Viet'), ('en', 'English')]
    USE_I18N = True

- API response:
    Tra ve ma loi (error codes), frontend tu dich
    VD: {"error": "SLOT_FULL"} -> frontend hien "Khung gio da day" / "Slot is full"

- Notification templates:
    vi: "Lich hen ngay {date} da duoc xac nhan"
    en: "Your appointment on {date} has been confirmed"
```

## Luu y

1. **Khong dich du lieu y khoa**: Chan doan, ghi chu cua bac si giu nguyen ngon ngu nhap
2. **ICD-10 co san 2 ngon ngu**: WHO cung cap ca English va moi quoc gia co ban dich
3. **Chat AI**: Khi user chon ngon ngu, system prompt cua LLM se yeu cau tra loi bang ngon ngu do
4. **Date format**: vi-VN dung DD/MM/YYYY, en-US dung MM/DD/YYYY
5. **Currency**: Luon dung VND (don vi Viet Nam dong)
6. **Bo sung ngon ngu moi**: Chi can them folder moi trong locales/ va them vao LANGUAGES
